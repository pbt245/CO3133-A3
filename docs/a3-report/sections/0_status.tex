\section*{Status of this Draft}
\addcontentsline{toc}{section}{Status of this Draft}

This is the draft report of milestone M2 (specification, section 6.13): \emph{Unimodal~A, Unimodal~B and
simple fusion implemented; quantitative results available.} The dataset proposal (M1) was approved by the
instructor.

\begin{itemize}
  \item \textbf{Done.} Pair building and validity checks including a manual audit of 200 pairs, the EDA, a grouped and committed train/validation split,
        the image-only baseline (UA), the text-only baseline (UB) and the simple concat fusion (F1), each trained
        with three seeds ($42$, $123$, $2026$). Two references without training are reported next to them:
        a keyword rule (K0) and a late fusion (F0). The comparison uses the decision rule of the proposal, with
        leakage-controlled test views and a first support/conflict analysis.
  \item \textbf{M3.} The improved cross-modal fusion (F2), the ablations (auxiliary losses E1, class-name masking E2,
        modality removal E-mod), the error taxonomy, the final report, slides, video and public checkpoints.
\end{itemize}

Every number comes from the committed split (\texttt{data/splits/split.json}) and from code commit
\texttt{cfc509a}, which is recorded in the \texttt{env.json} file of every run (working tree clean).
